| Mariana | Mariana Supermercado (cliente) |
| Terça-feira Suína | Campanha de terça do Mariana com carnes suínas |
| porquinho / Carne Suína | Mascote chef porco com cutelos, `public/carne-suina.png` |
| selo | Selo da campanha; o "Terça-feira Suína" agora é desenhado em código (`SeloTerca` em ui.tsx), reto e sem cabo |

| pacote semanal | Serviço recorrente de vídeos de ofertas oferecido aos mercados |
| estouro | Estrela amarela girando atrás do preço |
